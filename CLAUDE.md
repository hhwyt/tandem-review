# CLAUDE.md

## Writing the skill and the docs

- `skill/SKILL.md` and `docs/` serve every project in every field, not one project or domain. Keep
  out examples, terms and rules that come from a particular project or field.
- Write rules as general principles the agent applies with its own judgment. Do not fix wording,
  templates or steps beyond what the page format needs: over-specific rules limit what the agent
  can do.
