PR 切换控件 · 5 个原型

为 Tandem Review 顶栏「切换 PR」功能做的 5 个可点击 HTML 原型，供产品负责人挑选。

方案 A 下拉菜单 顶栏内嵌下拉，支持搜索过滤，键盘 ↑↓ 选择、Enter 切换。 打开 →
方案 B 命令面板 ⌘K / Ctrl+K 弹出中央命令面板，带遮罩与缩放动画。 打开 →
方案 C 左侧窄栏 页面最左边 56px 竖栏，色块切换，悬停弹出提示卡。 打开 →
方案 D 顶部标签页 浏览器式标签页，可关闭标签，也可从 + 重新打开。 打开 →
方案 E 面包屑 + 弹出卡片 三段面包屑，仓库段弹仓库列表，PR 段弹分组卡片。 打开 →

所有方案共享同一份 4 个 PR 的假数据，配色为 GitHub 浅色主题。
